# Changelog / 更新日志

WebUI changes are documented in this file.
WebUI 相关变更统一记录在此文件。

## [0.1.0] - 2026-09-18

### Changed / 变更

- The tag filter now shows only the top 6 tags by count; "Show more" opens a floating submenu with the remaining tags, and the previous 16-tag cap was removed.
- 标签筛选默认只显示数量最多的 6 个标签，“展开更多”以浮层子菜单展示其余标签；取消原先最多 16 个标签的限制。
